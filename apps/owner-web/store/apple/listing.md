## Description (max 4000 characters)

```
Array Operator brings your solar fleet to the phone.

Check production and site health, walk the array and inverter tree, manage offtaker invoices, and work with Energy Agent — the same account you already use on the web.

FLEET PULSE
See how the fleet is performing without opening a laptop. Refresh telemetry when you need a current read. Drill into arrays and inverters when something looks off.

OFFTAKER INVOICES
Maintain offtakers, preview invoice PDFs, and follow the send pipeline from a mobile layout built for one-handed use.

ENERGY AGENT
Ask for help on fleet status, billing prep, and small operational adjustments. Important writes stay behind a confirm step so you stay in control.

CONNECT
Link monitoring paths (including SolarEdge and portal vendors) and payment setup via Stripe Connect where your account supports it.

SECURE SESSIONS
Sign in with your Array Operator credentials (password or magic link). Sessions use the same authentication model as the desktop product.

Array Operator / EnergyAgent builds tools for owners and operators who take production, RECs, and offtaker relationships seriously.

Support: support@arrayoperator.com
Privacy and terms: see the Privacy Policy URL on this listing.
Web: https://arrayoperator.com
```
