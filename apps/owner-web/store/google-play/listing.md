## Full description

```
Array Operator is the phone-first control surface for solar fleet owners and operators.

See your whole fleet at a glance: production pulse, array and inverter status, and the signals that matter when you are away from the desktop. Connect monitoring vendors, review offtaker invoices, and ask Energy Agent to help with day-to-day adjustments — with confirmations before anything important is written.

BUILT FOR OWNERS ON THE GO
• Fleet home — production and health in one place
• Array and inverter tree with refresh when you need fresh telemetry
• Offtaker invoices — create, preview PDFs, and track the send pipeline
• Energy Agent — chat-style help for fleet and billing tasks, with confirm-before-write
• Connect — SolarEdge and other monitoring paths, portal vendors, Stripe Connect for payments
• Account and session security with the same sign-in you use on the web

WHO IT IS FOR
Independent owners, small operators, and teams who already use Array Operator / Energy Agent on the web and want the same account on a phone.

PRIVACY
We do not sell your data. Accounts, fleet telemetry, offtaker records, and agent sessions are used to run the product. See the in-app privacy policy for details.

Requires an Array Operator account. Some features depend on connected monitoring vendors and your plan.

Support: support@arrayoperator.com
Company: Array Operator / EnergyAgent
```
