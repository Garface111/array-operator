# Vermont — special case (NOT a standard service-mark filing)

## Hard rule from VT SOS trademark form

Vermont **does not register service marks**. State trademarks are for **goods** only  
(9 V.S.A. Ch. 71). Array Operator is **SaaS / services**, so a VT trademark application  
for “ARRAY OPERATOR” as software services would be **improper**.

## What to do instead

### A. Rely on federal + common law (recommended baseline)
- File **USPTO** Class 42 for ARRAY OPERATOR  
- Common-law rights from actual use in Vermont  

### B. Optional: Vermont trade name (DBA)
If Dyson Swarm Technologies LLC does business in Vermont **as** “Array Operator”:
- Register a **trade name / assumed name** via VT bizfilings  
- https://bizfilings.vermont.gov/homepage  
- This is **name registration**, not trademark exclusivity  

### C. Do **not**
- File a VT trademark claiming physical “goods” to force a SaaS brand through
