## 6. Vermont note (don’t ignore)

Vermont’s own form states trademarks are for **goods, not services**. Array Operator is a **service** mark (SaaS).  
**Do not file a VT “trademark” pretending Array Operator is physical goods.**  
For VT presence: federal registration + optional **trade name** registration under 11 V.S.A. if you use the name in Vermont.
