# Offtaker Invoice Generator — demo video kit

**Goal:** A short screen recording of *you* setting up and running the offtaker invoice generator, suitable for sales / onboarding / LinkedIn.

**Recommended length:** 4–7 minutes (tight cut can be 2:30).

**Account to film with (pick one):**
| Account | Why |
|---------|-----|
| **HCT / Paul** (`pbozuwa@…`) if you have access | Real offtakers + real utility bills — most credible |
| **Sunrise Commons (Demo)** `ten_anna_800` | Huge roster for bulk-import B-roll; mark as demo |
| Fresh trial on arrayoperator.com | Best for pure “setup from zero” story (longer) |

**URL entry points**
- App: https://arrayoperator.com
- Invoices tab: https://arrayoperator.com/#reports
- Jump straight to bulk import: https://arrayoperator.com/?setup=offtakers#reports  
  or `/?bulk=1#reports`

**Tools**
- macOS: QuickTime (File → New Screen Recording) or Loom  
- Windows: Win+G (Xbox Game Bar) or OBS Studio (free)  
- Record **browser only** (not full desktop); 1080p; 30 fps; system audio off unless you mic

**Prep (2 minutes before record)**
1. Sign in to the chosen account.
2. Confirm Invoices header shows **bill sources** (“✓ N bill sources”) if you will demo a real send preview.
3. Close extra tabs; zoom browser to **100–110%**; hide bookmarks bar.
4. If using a demo tenant, say so once on camera (“this is a demo fleet”).
5. Optional: have a sample offtaker roster `.xlsx` on the Desktop for bulk import.

## Structure (use as timeline)

| # | Time | On screen | What you say (voiceover) |
|---|------|-----------|---------------------------|
| 1 | 0:00–0:25 | Landing or Fleet, then click **Invoices** | “This is Array Operator. Owners monitor the fleet *and* invoice offtakers from settled utility bills—not from inverter guesses.” |
| 2 | 0:25–0:50 | Invoices → **Offtakers** list | “Each row is one offtaker—someone who buys a share of an array’s output. Invoices are drafted from utility bills when the period is ready.” |
| 3 | 0:50–1:40 | Click **⬆ Bulk import** (or open `?setup=offtakers`) | “Most operators don’t type offtakers one by one. Drop any membership spreadsheet—utility export or your own Excel. We detect columns and you confirm the mapping.” |
| 4 | 1:40–2:30 | Column mapping + row review | “Required: name, share, and array or account number. Weak matches need a confirm so we never silent-wrong an invoice.” |
| 5 | 2:30–3:10 | Commit a few rows *or* open an existing offtaker | “Once committed, offtakers land here with share, array, and bill source.” |
| 6 | 3:10–4:00 | Open one offtaker: MASTER / SUB dropdowns | “Two bindings: **Master** is the net-meter group host. **Sub** is optional—the offtaker’s own meter. Share % drives the bill math. We never invent kWh from inverters.” |
| 7 | 4:00–4:40 | Delivery mode + send-to-me | “Default is approval: nothing emails a customer until you approve. Start with send-to-me so the first draft lands in your inbox.” |
| 8 | 4:40–5:30 | Preview / draft / bill accuracy if available | “When a utility bill covers the period, you get a draft with the figures and a cross-check against GMP allocation when we have the data.” |
| 9 | 5:30–6:00 | Trends or list close-up | “Trends shows offtaker revenue as the book grows. Setup once; bills drive the cycle.” |
| 10 | 6:00–6:20 | End on Invoices | “That’s offtaker invoicing in Array Operator—utility-settled, reviewable, and built for real rosters.” |

**Cut if short on time:** skip bulk import (use an existing offtaker) → 2:30 total.

## Shot checklist (must-capture)

- [ ] Invoices tab open (not “Reports” wording in voice—UI says **Invoices**)
- [ ] Offtakers list with at least 2–3 named rows
- [ ] Bulk import button + file drop (or “Add offtaker” manual form)
- [ ] Master / Sub / share % on an offtaker card
- [ ] Approval / send-to-me control
- [ ] One draft or email preview (even if send-to-me only)
- [ ] Optional: Bill audit chip or accuracy section if green/flagged

---

## What not to show / say

- Don’t show real customer emails if filming a live tenant for public use—blur or use demo.
- Don’t claim invoices use **inverter kWh** (they use **utility bills**).
- Don’t send a real customer during the take—use **to me** / approval.
- Don’t leave password managers or other tenants visible in the tab strip.

1. Trim dead air; keep cursor slow on forms.

4. Title: **“Array Operator — Offtaker invoice setup in 5 minutes”**
5. Upload: Loom (unlisted link for sales) + MP4 on Desktop/Drive.
